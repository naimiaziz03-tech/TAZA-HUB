# تطبيقاتي (TAZA) — تطبيق واحد بأربعة أقسام

| القسم | محتواه |
|---|---|
| الحجز | تطبيق Réservation |
| CRTE والتحضير | تقرير الأشغال والاختبارات + ورقة التحضير (تطبيق واحد) |
| القياس | فيش مراقبة واختبار المحول TAZA II |
| المحطات | بحث محطات TAZA وأقسامي |

كل قسم هو نفس تطبيقه السابق بلا تغيير في وظائفه، موضوع داخل مجلده في `apps/`.

## النشر على GitHub Pages
1. أنشئ مستودعا جديدا (مثلا `taza-hub`)، Public.
2. ارفع **محتوى** هذا المجلد كما هو، بما فيه مجلد `apps` والملف المخفي `.nojekyll`.
3. Settings ← Pages ← Deploy from a branch ← main و `/ (root)`.
4. افتح الرابط في Chrome ثم ⋮ ← «تثبيت التطبيق» (أو من قائمة ⋮ داخل التطبيق).

افتح التطبيق أول مرة وأنت متصل بالإنترنت، وبعدها يعمل بدون إنترنت.

## البيانات القديمة
إذا نشرت المستودع الجديد تحت نفس حساب GitHub Pages القديم (نفس العنوان `اسمك.github.io`)
تبقى بياناتك المحفوظة في الهاتف ظاهرة في الأقسام، لأن المتصفح يخزنها لكل عنوان رئيسي.
لا تمسح «بيانات الموقع» لـ github.io. وقبل حذف التطبيقات القديمة خذ نسخة احتياطية من داخلها.

## النسخة الاحتياطية الشاملة
في الصفحة الرئيسية: «تنزيل نسخة شاملة» يحفظ ملفا واحدا `TAZA_backup_....json` فيه بيانات كل الأقسام
والملفات المرجعية والصور. و«استرجاع نسخة» يعيدها في هذا الهاتف أو في هاتف جديد (بعد نشر التطبيق وفتحه).
الاسترجاع يستبدل بيانات الأقسام الموجودة في النسخة. أما كود التطبيق نفسه فمصدره المستودع على GitHub.

## التحديث
استبدل الملفات المتغيرة في المستودع. لإظهار شريط «يتوفر إصدار جديد» غيّر `VER` في `sw.js`
(مثلا `tazahub-v2`). ويمكن أيضا من ⋮ ← «تحديث التطبيق».

## إضافة تطبيق جديد لاحقا
1. أنشئ مجلدا `apps/اسم-التطبيق/` وضع فيه ملفات التطبيق (`index.html` وغيره).
2. في `apps.js` انسخ أحد الأسطر وغيّر: `id` و`title` و`sub` و`color` و`icon` و`path`
   وقائمة `files` (كل ملفات المجلد) و`cdn` (روابط المكتبات الخارجية إن وجدت).
3. في الملف الرئيسي للتطبيق الجديد لا تسجّل service worker؛ التطبيق الرئيسي يتكفل بذلك.
   وحتى تدخل بياناته في النسخة الاحتياطية الشاملة، عبّئ `storage` في سطره: `ls` أسماء مفاتيح localStorage
   (ويقبل `*` في آخر الاسم)، و`idb` قواعد IndexedDB (`db` و`version` و`store` و`keyPath` إن وجد و`autoInc`).
4. غيّر `VER` في `sw.js` ثم ارفع الملفات.
