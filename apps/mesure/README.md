# تطبيق اختبار المحول (TAZA II)

الملفات (كلها في نفس المجلد، في جذر المستودع):
- index.html — التطبيق
- manifest.json — بيانات التنصيب
- sw.js — العمل بدون انترنت + التحديث التلقائي
- reset.html — صفحة تنظيف النسخة القديمة (تُستعمل مرة واحدة)
- icon-v2-192.png و icon-v2-512.png و icon-v2-maskable-512.png — الأيقونات
- template.docx — قالب Word من الملف الأصلي (للاحتفاظ فقط)

## النشر على GitHub Pages
1. ارفع الملفات إلى جذر المستودع (استبدل القديمة، واحذف ملفات icon-192/512 القديمة).
2. Settings ← Pages ← Deploy from a branch ← main و/ (root).
3. الرابط: https://USERNAME.github.io/REPO/

## الانتقال من نسخة قديمة (مرة واحدة)
افتح في المتصفح: https://USERNAME.github.io/REPO/reset.html
تمسح النسخة القديمة من الهاتف وتفتح التطبيق الجديد. بياناتك المحفوظة تبقى.

## التحديثات القادمة
تلقائية: يفحص التطبيق الملفات الجديدة عند كل فتح ويعيد تشغيل نفسه. ويوجد زر «تحديث التطبيق» في الشريط للتحديث اليدوي.
رقم الإصدار يظهر أسفل الصفحة للتأكد من النسخة التي تعمل.

## التنصيب
- Android / Chrome: زر «تنصيب التطبيق» داخل البرنامج، أو القائمة ⋮ ← «تثبيت التطبيق».
- iPhone / Safari: المشاركة ← «إضافة إلى الشاشة الرئيسية».
